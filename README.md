# COTree

This is a Python implementation of COTree framework developed for multi-omics cell trajectory data analysis [<a href=https://www.biorxiv.org/content/10.1101/2025.10.30.685684v1>link</a>].

A complete working example is located in COTree.ipynb.

## Install
```bash
pip install git+https://github.com/BoYuan07/cotree.git
```

## Usage
```python
import cotree
print(cotree.__version__)
```
